# 🌍 Memory Map

Memory Map is an aesthetic and interactive web application that lets you pin your favorite memories on a global map. 📍✨  
Attach a title, description, and even a photo to each location and revisit your moments visually anytime!

---

## 🚀 Features
- 🗺️ Interactive Map (using Leaflet.js)
- 📝 Add new memories with title, description, and photo
- 📸 Upload image memories
- 🔍 Real-time search functionality
- 🌙 Dark mode toggle
- 💾 Auto-save and load memories using Local Storage

---

## 🎨 Tech Stack
- **HTML5** 
- **CSS3** 
- **JavaScript**
- **Leaflet.js** (for map)
- **LocalStorage API** (for saving memories)
